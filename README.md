# HUD holográfico

Un tema para la app de escritorio de Claude: azul marino profundo, luz cian, fondo animado (reactor de anillos, radar, barras de datos, partículas), mensajes con marcos tipo HUD y letra mono. Sonido ambiental opcional (botón del altavoz en la barra de la sesión).

Solo modo oscuro. La terminal y los editores no dibujan temas.

## Instalar

En la línea de comandos de una sesión de Claude Code en terminal:

```
/plugin install hud-holografico --marketplace mpereira17-uc/hud-holografico
```

Responde `y` para añadir el marketplace y elige el alcance de usuario.

Desde una shell:

```
claude plugin install hud-holografico --marketplace mpereira17-uc/hud-holografico
```

En la app de escritorio, donde `/plugin` no funciona: pulsa + junto a la caja de mensaje, luego Plugins, Add marketplace con `mpereira17-uc/hud-holografico`, y después Add plugin.
